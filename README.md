# ShortsAway

A privacy-first Android utility that helps you pause short-form video feeds and reclaim your attention.

## Website

The site is a static GitHub Pages site. In the repository settings, enable **Settings → Pages → Deploy from a branch**, select `main` and `/ (root)`.

## Pages

- `index.html` — ShortsAway landing page
- `privacy.html` — privacy policy

All artwork is in `assets/`. The policy source provided with the project is preserved as `PRIVACY_POLICY.md`.
